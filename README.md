# 🎁 Happy Birthday, Maxi!

A little interactive birthday surprise for Maxi.

Live at: https://badassprasad.github.io/happy-birthday-baby/

## What it is

1. A welcome screen
2. 6 gift boxes to tap open, each revealing a sweet note
3. A cake with 5 candles to blow out and make a wish
4. A final celebration screen with confetti, balloons, and a birthday message

## Adding her funny photo

Drop a photo file named `meme.png` into this folder (same folder as `index.html`) and push it.
It will automatically show up on the final celebration screen. Until then, a placeholder 📸 is shown instead.
